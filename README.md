# Stars — a Home Screens plugin

Stars for jobs ticked off in a Todoist project this week, a daily streak, and a goal/reward.

Install: Home Screens editor → Plugins → Install from URL…

```
https://github.com/tweetyboopdev2022-code/home-screens-nora-stars/releases/latest/download/nora-stars.tgz
```

Build: `npm install && npm run build`
